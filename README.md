# ZenZap 🌿⚡  
### Find Your Zen, Feel the Zap.

ZenZap is a **UI/UX-focused mental wellness app** designed to help users track their mood and relax through calming visuals and playful mini-games.

This project focuses on **user experience, interface design, and interaction flow**, created using **Figma and frontend technologies**.

---

## 🧠 Project Overview
- Mood tracking with emojis
- Daily affirmations
- Refreshing mini games for stress relief
- Emergency calm button
- Colorful, calming UI design
- Smooth micro-interactions

---

## 🎯 Target Users
- College students
- Young adults
- Users seeking mental calm & stress relief

---

## 🛠 Tools & Technologies
- Figma (UI/UX & Prototype)
- HTML, CSS, JavaScript
- TypeScript
- Vite
